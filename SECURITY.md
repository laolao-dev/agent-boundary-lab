# Security Policy

Agent Boundary Lab is an alpha prototype. Do not use it as production security
enforcement, an operating-system sandbox, or proof of compliance.

## Reporting a security-sensitive issue

Use GitHub private vulnerability reporting for this repository if it is enabled.
If it is unavailable, contact the maintainer privately before opening a public
issue. Do not include exploit details that expose third parties, and never submit
real API keys, passwords, tokens, credentials, or private data.

For ordinary bugs that contain no sensitive information, a public issue is
appropriate.
